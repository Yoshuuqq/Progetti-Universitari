Reports of projects carried out during my studies in Automation and Control Engineering at Politecnico di Milano.

## Control of a PMSM–PMDC back-to-back setup

Automation and Control Laboratory, academic year 2024–2025, team of five.
Control of two coupled electric motors with a Texas Instruments F28069M microcontroller: sensor characterisation, parameter identification, cascaded PI, LQR and field-oriented control, sensorless control with a Kalman filter and a reduced-order observer, and a self-tuning adaptive controller based on recursive least squares.

## System hazard analysis of an Adaptive Cruise Control system

Preliminary hazard analysis, failure mode and effects analysis, fault tree analysis and event tree analysis of an adaptive cruise control system.
